# awesome-design-md (reference library)

Source: https://github.com/VoltAgent/awesome-design-md (MIT). Each `designs/<brand>/DESIGN.md` describes a site's visual language in 9 sections: Visual Theme, Color Palette & Roles, Typography, Component Stylings, Layout, Depth & Elevation, Do's and Don'ts, Responsive Behavior, Agent Prompt Guide.
This SKILL.md is a thin wrapper added for this project; the DESIGN.md files are unmodified upstream content.

## How to use
1. Pick one or two brands that match the request. Never load the whole folder.
2. Read `designs/<brand>/DESIGN.md`, then take the *principles* (spacing rhythm, type scale, elevation, motion, component anatomy) and apply them.
3. Keep this project's identity: VÉRION palette (gold + ice accent), EN/FA with RTL, dark + light theme, plain JavaScript. `AGENTS.md` always wins over a brief.
4. Do not copy another brand's logo, name, copy, imagery or trademarks. These briefs describe public CSS values and are provided as-is.

## Good starting points for VÉRION (luxury, 3D, motion)
- Luxury / automotive hero and spec layouts: `ferrari`, `lamborghini`, `bmw`, `bmw-m`, `bugatti`, `tesla`
- Calm premium product pages: `apple`
- 3D / tech showcase and motion-first sections: `nvidia`, `spacex`, `framer`, `webflow`, `runwayml`
- Dashboards / admin panels: `linear.app`, `vercel`, `stripe`, `sentry`, `posthog`
